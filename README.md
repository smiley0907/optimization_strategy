# Adaptive Optimization Strategy for Efficient Variational Quantum Algorithms

Comparison of Conventional VQA and Proposed Adaptive VQA using
target-aware optimization termination.

## Research Objective

This notebook evaluates whether target-aware termination can reduce
unnecessary optimization evaluations in Variational Quantum Algorithms.

The study compares:

- Conventional VQA
- Proposed Adaptive VQA

The primary performance metric is Iteration Reduction (%).
Final objective energy difference and execution time are used as
supporting metrics.
